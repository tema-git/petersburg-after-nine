# После девяти

Интерактивная прогулка по Петербургу: Radisson Sonya → Франс → Сидрерия → VNVNC. Сумбур можно добавить по дороге.

Статический сайт на HTML, CSS и JavaScript. Все шрифты, фотографии, картографические данные и библиотеки находятся в репозитории; ключи API, сборка и сервер приложений не нужны.

## Запуск

```sh
python3 -m http.server 51842
```

Откройте `http://localhost:51842/`.

## Публикация

Отдельный GitHub Pages репозиторий `tema-git/petersburg-after-nine`, ветка `main`, корень `/`.

Сайт: https://tema-git.github.io/petersburg-after-nine/

Пути к ресурсам относительные и работают в подпапке Pages. `robots.txt` и meta robots просят поисковые системы не индексировать путеводитель.

## Возможности

Кликабельная карта, описания и реальные фото пяти мест, галерея, планировщик остановок с итоговым временем, дополнительная ветка маршрута, отметки посещений, копирование ссылки с настройками, сохранение плана в TXT, игра из пяти загадок и локальная подготовка запроса на стол.

Персональные данные формы не отправляются и не записываются в хранилище. Настройки плана могут передаваться в URL; имён, телефонов и отметок посещения в ссылке нет. Перезагрузка очищает состояние посещений и игры.

## Источники

- Карта: OpenStreetMap contributors, ODbL; маршрутизация FOSSGIS OSRM. Атрибуция видна на карте.
- Фото: открытые карточки конкретных заведений на Яндекс Картах и официальный сайт Sumbur Bar. Источники перечислены в `photo-sources.json` и в интерфейсе. Права на фотографии принадлежат владельцам снимков.
- Шрифты Golos Text и Prata: SIL Open Font License, тексты лицензий находятся в `assets/fonts/`.
- D3 7.9.0 и GSAP 3.15.0 / ScrollTrigger: локальные поставки с исходными заголовками лицензий.
- Решения по дизайну и открытые референсы: `DESIGN.md`.

Программы заведений и условия входа следует подтверждать по ссылкам организаторов. Расчёт времени не включает ожидание стола, очередь и светофоры. Сайт не создаёт настоящие брони и не продаёт билеты.
